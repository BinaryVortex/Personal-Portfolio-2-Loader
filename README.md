# Personal Portfolio 2 Loader

Personal Portfolio 2 Loader — a minimal, responsive portfolio landing page with a smooth loading animation built using HTML, CSS and JavaScript.

![Preview](./Screenshot%202024-08-28%20082730.png)

## Overview

This repository contains a lightweight portfolio template focused on a clean loader animation and a simple personal-introduction layout. It's ideal for students, developers, and designers who want a ready-to-use starter to showcase projects and contact info.

## Features

- Smooth CSS loader animation
- Responsive layout (desktop & mobile friendly)
- Simple, easy-to-read HTML structure
- Lightweight — no frameworks required

## Demo / Preview

Open `index.html` in your browser to view the project locally. The loader animation will show on page load and reveal the portfolio content.

## Files

- `index.html` — main HTML file
- `style.css` — styles and loader animation
- `Screenshot 2024-08-28 082730.png` — preview screenshot used in this README

## Run locally

1. Clone the repo:

   git clone https://github.com/BinaryVortex/Personal-Portfolio-2-Loader.git

2. Open `index.html` in your browser (double-click or right-click → Open with...).

No build tools or npm dependencies are required.

## Customize

- Modify `index.html` to change your name, bio, links, or sections.
- Edit `style.css` to tweak colors, spacing, and the loader animation.
